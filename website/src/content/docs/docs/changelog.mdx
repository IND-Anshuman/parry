## 0.3.0 <Badge text="2026-11-05" variant="tip" />

Production credibility. See
[CHANGELOG.md](https://github.com/IND-Anshuman/parry/blob/main/CHANGELOG.md) for
the full list.

**Observability**
- OpenTelemetry GenAI exporter (`parry.integrations.otel.instrument()`): one span
  per call with `gen_ai.*` usage/request attributes and `parry.*` extensions,
  into your own provider. Backed by a general `guard.add_observer(fn)` hook.
- `parry doctor`: plain-language findings (cache hit rate, estimated/unpriced
  costs, rate-limit rejections, spend concentration) as `guard.doctor()` or
  `parry doctor --db parry.db`.

**Reach**
- Multi-key rotation (`guard.set_keys(provider, keys)`): spread calls over
  several keys to multiply per-org rate limits; rests a key on a `429`.
- LiteLLM shim (`parry_litellm`): guard existing LiteLLM code with one import.

**Docs**
- Migration guides (LiteLLM, Helicone) with a comparison, and a recipe set
  (multi-tenant, FastAPI, agents, batch, fine-tunes).

## 0.2.0 <Badge text="2026-11-03" variant="tip" />

Cost-model correctness and provider reach. See
[CHANGELOG.md](https://github.com/IND-Anshuman/parry/blob/main/CHANGELOG.md) for
the full list.

**Cost**
- Pricing tiers: cached input, 5m/1h cache writes, batch and fast/priority, via
  `compute_tiered` / `record_tiered` / `tier_rates` and `parry pricing --tiers`.
- Cache-aware usage: cache-read and cache-write tokens are split out and billed
  at the cache rate.
- Fail-closed `on_unpriced` (default `"raise"`): an unpriced model raises
  `UnpricedModel` instead of slipping past the budget at $0.
- Anthropic 4.7+ tokenizer multiplier (~1.30×) in pre-flight estimates.
- Pricing sync from LiteLLM's live database (`scripts/sync_pricing.py`).

**Providers**
- `install()` now also guards Groq, Together, Google `google-genai`, Ollama,
  Mistral and Cohere when their SDKs are installed, each with an opt-out flag.
- AWS Bedrock Converse via `parry.integrations.bedrock.guard`.
- Guides for the OpenAI Agents SDK and Pydantic AI.

## 0.1.0 <Badge text="2026-10-25" variant="tip" />

The first release. See also [CHANGELOG.md](https://github.com/IND-Anshuman/parry/blob/main/CHANGELOG.md) and [GitHub releases](https://github.com/IND-Anshuman/parry/releases).

**Hooks**
- `parry.install()` hooks OpenAI chat completions, the OpenAI Responses API,
  Anthropic messages and Anthropic beta messages, on sync and async clients,
  including `.with_raw_response` and `stream=True`.

**Guard**
- Response cache: a blake3 key over the canonicalised semantic request, a
  bounded moka LRU with TTL, and optional SQLite persistence.
- Per-model token-bucket rate limiting with tier-1 defaults, `"wait"` or
  `"raise"` semantics, burst and tokens-per-minute limits.
- Cost tracking from a dated pricing table, matched by longest prefix, with
  per-model and per-day totals.
- `max_cost_usd` budget, checked before each request is sent.
- Retry with exponential backoff, equal jitter and `Retry-After`.

**Scoping**
- `with Parry():`, `parry.wrap(client)`, `parry.bypass()`.

**Integrations**
- LangChain `ParryCallback` and LlamaIndex `ParryHandler`.

**Tooling**
- The `parry stats` and `parry pricing` CLI.
- Standalone Rust primitives: `Cache`, `RateLimit`, `Cost`, `Retry`,
  `count_tokens` and `estimate_tokens`.
- Published on PyPI as `llm-parry` and imported as `parry`.
